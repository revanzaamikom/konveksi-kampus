# Direction contract — KonveksiKampus home (redesign)

Reference-pinned world: **Modevo** (https://modevo-fashion.webflow.io/). Per `impeccable`
"the brief wins" — the user pinned this as the visual reference. Palette is NOT free: it stays
the client's own (charcoal `#0E0E12`, red `#E02030`, yellow `#F2B90C`).

- **Seed key:** user-pinned reference (supersedes the dealt roll `1f48462c`)
- **Mode:** Persuade
- **Build path:** code-led

## THESIS

**Premium industrial specimen catalogue.** The client's real assets are clean product cutouts on
a dark ground — not editorial model photography. Rather than fake a fashion-magazine look the
assets cannot carry, the page treats each garment as a _specimen_: photographed on the same dark
ground as the page, given wide margins, and framed by a strong condensed display type system.
Refuses both the fashion-editorial template (unsupported by assets) and the boxed card-grid
default (marketplace look).

## OWN-WORLD

Charcoal ground `#0E0E12`; brand red `#E02030` for the one action colour; yellow `#F2B90C` as
the single accent. Display type: **Anton** (condensed, uppercase). UI/body: **Instrument Sans**.
Pill buttons, hairline `#ffffff14` borders only where a control needs one, wide whitespace,
image-first sections with no decorative card chrome. Photographs sit directly on the page ground.
No gradients, no glass, no glow, no bordered card grids.

## STORY

Visitor: "This is a serious maker — here are the garments they produce, clearly" → "they can
produce mine" → taps WhatsApp. Proof is the garments themselves, catalogued with precision.

## FIRST VIEWPORT

Charcoal ground, generous top space. Giant Anton headline "KONVEKSI CUSTOM / SERAGAM & APPAREL"
(second line right-aligned). Below it, a 3-up row of real product photos on the same dark ground,
the centre column dropped for asymmetry. Then a wide whitespace band with the value line and the
red pill "Konsultasi via WhatsApp" + outline pill "Lihat Katalog".

## FORM

Editorial-media grid with a specimen treatment. Lead line — giant display type over an asymmetric
image row, all on one ground colour.

## FINISH

Unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict,
DESIGN.md, and every shipping raster carrying its provenance.
